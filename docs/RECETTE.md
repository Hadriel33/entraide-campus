# Recette : le test à la main, avec deux comptes

> Le cours : « Testé depuis un deuxième compte, pas seulement le tien », « Sur ton téléphone, avec un 2e compte, avec une saisie bizarre ».
> Compte A = Sam (ESP), compte B = Léa (ESD). B dans une **fenêtre privée** ou un autre navigateur. Coche au fur et à mesure, note le moindre souci en bas.

## 1. Comptes
- [ ] Inscription avec un email @gmail.com : **refusée** avec un message clair
- [ ] Inscription de A avec @mail-esp.com : l'école ESP est déduite toute seule, on arrive sur « Bienvenue » avec le tuto de Colette
- [ ] Déconnexion puis reconnexion : le compte existe toujours, on arrive sur « Mon bureau »
- [ ] Mot de passe de 7 caractères : refusé

## 2. Profil et IA n°1
- [ ] A dépose un CV PDF : Colette lit le CV, des compétences sont proposées, A en retire une et enregistre
- [ ] A dépose un PDF vide : aucune compétence inventée, la saisie à la main reste possible
- [ ] A choisit sa classe, sa Colette (couleur, tenue) ; une tenue à cadenas n'est pas sélectionnable
- [ ] A renseigne son téléphone dans « Mes coordonnées »

## 3. Annonces et IA n°2 (règle d'or n°2)
- [ ] A publie « Photos pour vos événements d'asso » : elle apparaît sur le mur après rechargement
- [ ] A publie une annonce avec son numéro dans le texte : quelques secondes après, sur l'annonce, Colette propose une version sans le numéro ; « Appliquer la correction » fonctionne
- [ ] B ouvre l'annonce de A : pas de bouton Modifier ; B colle `/annonces/<id>/modifier` dans l'adresse : refusé ou introuvable
- [ ] Saisie bizarre : titre de 3 caractères, description de 2 000 caractères, emoji : messages d'erreur clairs, rien ne casse

## 4. Mise en relation (règle d'or n°1)
- [ ] B ouvre l'annonce de A : **aucun numéro visible**. Onglet Réseau (clic droit, Inspecter) : aucune réponse ne contient le numéro de A
- [ ] B clique « Demander le contact » avec un message
- [ ] A voit la demande punaisée dans « À traiter » (bureau et Demandes), la cloche s'allume en direct
- [ ] A accepte : confettis, les coordonnées s'affichent **des deux côtés**, la discussion s'ouvre

## 5. Discussion (règle d'or n°3)
- [ ] A et B s'envoient un message : il arrive en direct de l'autre côté
- [ ] Un 3e compte C colle l'adresse `/demandes/<id>` de la discussion : introuvable

## 6. Gamification et campus
- [ ] B laisse un avis à A : les points et le badge de A bougent, le classement aussi
- [ ] A et B cochent « Apparaître dans le fil » : l'entraide apparaît dans le fil du campus ; si l'un des deux décoche, elle disparaît
- [ ] La carte affiche les annonces au bon quartier ; le mur en direct reçoit une nouvelle annonce sans recharger
- [ ] Mode tableau noir : tout reste lisible

## 7. Téléphone
- [ ] Tout le parcours ci-dessus depuis un téléphone (barre d'onglets en bas, bouton Publier)
- [ ] Partage de connexion du téléphone : l'appli marche

## 8. Admin
- [ ] Hadriel (admin) voit la file de modération, valide une annonce, valide une classe proposée
